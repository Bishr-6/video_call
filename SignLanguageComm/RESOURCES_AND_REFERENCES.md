## 💻 أوامر مهمة

### Node.js & npm
```bash
npm init                    # إنشاء مشروع جديد
npm install                 # تثبيت المكتبات
npm install -D package      # تثبيت مكتبة تطوير
npm update                  # تحديث المكتبات
npm audit                   # فحص الأمان
npm start                   # تشغيل التطبيق
npm test                    # اختبار
npm run build               # بناء الإنتاج
```

### Git
```bash
git clone repo              # استنساخ المشروع
git add .                   # إضافة التغييرات
git commit -m "msg"        # حفظ التغييرات
git push                   # نشر إلى GitHub
git pull                   # سحب التحديثات
```

### Docker (اختياري)
```bash
docker build -t app .      # بناء صورة
docker run -p 5000:5000    # تشغيل الحاوية
```

## 📞 الدعم الفني

### للمشاكل الشائعة
```
❌ Port already in use
✅ تحديد Port مختلف أو استخدام kill-port

❌ npm ERR! (Missing package)
✅ حذف node_modules و .lock file وإعادة install

❌ Out of memory
✅ زيادة حد الذاكرة: node --max-old-space-size=4096

❌ CORS Error
✅ تحقق من إعدادات CORS في server.js
```
