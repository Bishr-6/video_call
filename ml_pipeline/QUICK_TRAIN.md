
---

## 📝 كيف يعمل السكريبت؟

يقرأ اسم كل فيديو → يستخرج اسم الحرف → يعالج الفيديو → يدرب النموذج

### مثال:
```
مجلدك يحتوي على:
    ا.mp4  →  حرف "ا"
    ب.mp4  →  حرف "ب"
    ت.mp4  →  حرف "ت"
    ...

السكريبت يقوم بـ:
1. ✅ قراءة جميع الفيديوهات
2. ✅ استخراج اسم الحرف من اسم الفيديو
3. ✅ معالجة كل فيديو وكشف الأيدي
4. ✅ حفظ البيانات في MP_Data
5. ✅ تدريب النموذج تلقائياً
6. ✅ حفظ النموذج النهائي
```

---

## ⚙️ التفاصيل

### الخطوات التي يقوم بها:

```
🎬 معالجة الفيديوهات
    ├── قراءة كل فيديو
    ├── كشف الأيدين بـ MediaPipe
    ├── حفظ البيانات (Keypoints)
    └── تنظيم البيانات بناء على اسم الحرف

🧠 التدريب
    ├── بناء الشبكة العصبية (CNN-BiLSTM)
    ├── تدريب النموذج على البيانات
    ├── حساب دقة التدريب
    └── حفظ النموذج النهائي
```

### النتيجة النهائية:

```
✅ sign_language_model.h5      ← النموذج المدرب
✅ label_map.json              ← خريطة الحروف
✅ Logs/                        ← سجلات التدريب
```

## ❓ الأسئلة الشائعة

### س: ماذا لو كانت البيانات موجودة بالفعل في MP_Data؟

**ج:** السكريبت سيستبدلها بالبيانات الجديدة. إذا أردت حفظ القديمة:
```bash

Rename-Item MP_Data MP_Data_backup
```

### س: كم عدد الفيديوهات المطلوبة لكل حرف؟

**ج:** فيديو واحد 10-30 ثانية كافٍ، لكن 2-3 فيديوهات أفضل للدقة

### س: ماذا لو حدث خطأ أثناء المعالجة؟

**ج:** السكريبت سيتخطاه ويستمر مع الفيديوهات الأخرى
