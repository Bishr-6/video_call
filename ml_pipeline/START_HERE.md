# 🚀 البدء السريع - تدريب على الإشارات

## ⚡ الطريقة الأسرع (أمر واحد!)

إذا كانت لديك **جميع الفيديوهات جاهزة** في مجلد واحد:

```bash
# من داخل ml_pipeline
python train_all_from_folder.py "C:\path\to\your\videos"
```

**مثال:**
```bash
python train_all_from_folder.py "C:\Users\HP ENVY 15\Downloads\signals"
```

يقوم بـ:
- ✅ قراءة أسماء الفيديوهات
- ✅ استخراج اسم الحرف من كل فيديو
- ✅ معالجة جميع الفيديوهات
- ✅ تدريب النموذج تلقائياً

🎯 **لا حاجة لأوامر إضافية!**

## 💡 ملخص الإجابات

| السؤال | الإجابة |
|------|--------|
| أسرع طريقة؟ | ⚡ `train_all_from_folder.py "path"` |
| هل يمكن من screenshot؟ | ✅ نعم، استخدم `process_dictionary_screenshots.py` |
| أين أحفظ الملفات؟ | 📁 أي مكان - ستحدد المسار عند التشغيل |
| هل سينجح؟ | ✅ نعم إذا كانت اليدين واضحة |
| هل يمكن فيديو؟ | ✅ نعم - استخدم `train_all_from_folder.py` (الأفضل!) |
